1. Languages Used:
HTML: The structure of the webpage is built using HTML. It defines the layout and elements, including the map container (#map), location details container (#location-details), and weather popup (#weather-popup).
CSS: CSS is used to style the elements such as the map, location button, weather popup, and location details box. Specific styles like width, height, position, and hover effects are used to improve the appearance of the page.
JavaScript: JavaScript is used to add interactivity to the webpage. It handles dynamic actions like displaying the map, loading GeoJSON layers, interacting with APIs, and updating the map based on user location or weather information.

2. JavaScript Libraries and APIs Used:
Leaflet.js: A powerful open-source JavaScript library for building interactive maps. It handles the map initialization, layers, markers, and popups.
Axios: A promise-based HTTP client for making HTTP requests. Used to fetch data from external APIs like weather data and geolocation information.
OpenCageData API: Provides geolocation information based on latitude and longitude.
WeatherAPI: Fetches real-time weather data for a given location.

3. Functionality of the Code:
- Map Initialization: The map is created using Leaflet.js, with zoom controls and a base layer from OpenStreetMap.
- GeoJSON Layers: Multiple GeoJSON files representing geographic features are loaded dynamically using Axios.
- Weather and Location details: Real-time weather and location details are fetched and displayed dynamically based on user interactions.
